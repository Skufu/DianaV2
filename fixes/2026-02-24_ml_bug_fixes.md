## Bug #1: Threshold Never Applied at Inference

### Severity: CRITICAL

### Description
The optimized decision threshold from LOGO cross-validation was saved in the training report but never loaded at inference time. The predictor always used the default 0.5 threshold.

### Root Cause
- **Training** (`train_binary_v2_no_bp.py`): Saved `mean_threshold` nested inside `metrics` object
- **Inference** (`predict.py`): Looked for `decision_thresholds` key at top level → Key not found → Fell back to 0.5

### Impact
- Paper reported sensitivity/specificity at optimized threshold (~0.45)
- Production model always used 0.5 threshold
- Actual model performance differed from reported metrics

### Fix Applied

**File:** `Ian_ML/training/train_binary_v2_no_bp.py`

```python
# Before (line 822):
"validation_method": "Nested LOGO (outer) + GroupKFold Pipeline CV (inner)",
"metrics": {

# After (line 822-825):
"validation_method": "Nested LOGO (outer) + GroupKFold Pipeline CV (inner)",
"decision_thresholds": {
    "at_risk": float(best_row["Mean_Threshold"])
},
"metrics": {
```

### Verification
After retraining with fixed script, the saved report now contains:
```json
{
  "decision_thresholds": {
    "at_risk": 0.45666666666666655
  }
}
```

## Bug #2: Metabolic Syndrome Score Training-Serving Skew

### Severity: CRITICAL

### Description
The `metabolic_syndrome_score` feature was computed differently during training vs inference, causing systematic underprediction of risk for obese postmenopausal women.

### Root Cause
- **Training** (`train_binary_v2_no_bp.py`): 4 criteria → max score = 4
  - high_tg (triglycerides > 150)
  - low_hdl (hdl < 50)
  - high_bmi (bmi >= 25)
  - high_waist (waist_circumference >= 80) ← INCLUDED

- **Inference** (`predict.py`): 3 criteria → max score = 3
  - tg > 150
  - hdl < 50
  - bmi >= 25
  - ← WAIST CHECK MISSING

### Impact
Every patient with waist ≥80cm arrived at inference with a score 1 point lower than the model was trained to expect. This systematically underpredicted risk for obese postmenopausal women — the exact target population.

### Fix Applied

**File:** `Ian_ML/service/predict.py`

```python
# Added after line 601 (waist processing):
# Add waist criterion to match training (metabolic syndrome requires waist >= 80)
if not np.isnan(waist) and waist >= 80:
    metabolic_score += 1
```

```bash
OK
```
