Binary vs 3-Class Classification (Screening Tool - NOT for Diagnosis)
ModelTargetClassesUse Case
3-classdiabetes_labelNormal / Pre-diabetic / DiabeticScreening (low AUC - not diagnostic)
binaryat_risk_binaryNormal (0) / At-Risk (1)Screening (Pre-diabetic + Diabetic = At-Risk)
IMPORTANT: This is a screening tool only, NOT for diagnosis. The 3-class model has low AUC-ROC and should not be used for diagnostic purposes. Binary model prioritizes sensitivity for screening.
