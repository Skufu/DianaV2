🔐 Authentication Flow

User login, JWT issuance, and session management

sequenceDiagram actor User participant FE as Frontend participant BE as Backend participant DB as PostgreSQL participant Redis as Redis User->>FE: Enter credentials FE->>BE: POST /auth/login BE->>DB: GetUserByEmail() DB-->>BE: User record BE->>BE: bcrypt.CompareHash alt Invalid credentials BE-->>FE: 401 Unauthorized FE-->>User: Show error message else Valid BE->>BE: Generate Access & Refresh JWTs BE->>Redis: Cache session metadata BE-->>FE: 200 OK + JWTs FE->>FE: Store tokens securely FE-->>User: Redirect to Dashboard end

📝 Assessment Creation Flow

End-to-end flow from biomarker submission to ML prediction

sequenceDiagram actor User participant FE as Frontend participant BE as Backend participant ML as ML Service participant DB as PostgreSQL participant Redis as Redis User->>FE: Submit biomarkers FE->>BE: POST /assessments BE->>BE: Validate inputs & schema alt Validation Failed BE-->>FE: 400 Bad Request else Valid BE->>ML: POST /predict (16 features) alt ML Error ML-->>BE: Error/Timeout BE->>BE: Log Error BE-->>FE: 500 Internal Error else Success ML->>ML: Impute -> Scale -> Predict ML-->>BE: {cluster, risk, shap_values} end BE->>DB: CreateAssessment() BE->>Redis: Invalidate user cache BE-->>FE: 201 Created FE-->>User: Show Results + Risk Gauge + SHAP end

👑 Admin Dashboard Flow

Real-time admin monitoring via Server-Sent Events (SSE)

sequenceDiagram actor Admin participant FE as Admin UI participant BE as Backend participant SSE as SSE Broker participant DB as PostgreSQL participant Redis as Redis Admin->>FE: Access Dashboard FE->>BE: GET /admin/dashboard BE->>BE: Validate Admin Role (JWT) alt Not admin BE-->>FE: 403 Forbidden else Admin BE->>Redis: Get cached stats alt Cache miss Redis-->>BE: nil BE->>DB: Query Aggregates DB-->>BE: Stats Data BE->>Redis: Cache (TTL 5m) end BE-->>FE: Dashboard Data JSON FE->>BE: GET /admin/events/stream BE->>SSE: Register Client loop Real-time Events BE->>SSE: Publish Event (e.g. login) SSE-->>FE: Push Event Payload FE->>FE: Update UI end end
