# Validation Scripts

> Purpose: run doctor-validation predictions for the clinical_3class model.

---

## Scientific Use Guardrail

Use this folder for **prediction runs only**.  
Evidence claims (AUC, CV, thresholds, calibration) must come from
`models/clinical_3class/results/*` generated by the clinical_3class training pipeline.

Do not generate evaluation evidence from ad-hoc or synthetic scripts.

---

## Quick Start

```bash
# 1) Retrain/refresh artifacts (recommended before a validation cycle)
bash scripts/dev/retrain-clinical.sh

# 2) Verify artifact consistency
python scripts/thesis/generate_defensibility_outputs.py

# 3) Run doctor validation batch
python scripts/validation/run_validation.py --input your_patients.csv --output results.csv
```

## Input CSV Schema

```csv
patient_id,bmi,triglycerides,ldl,hdl,age,systolic,diastolic,smoking,activity,alcohol
```

Field ranges enforced by predictor:

- `bmi`: 10-80
- `triglycerides`: 20-1500
- `ldl`: 10-400
- `hdl`: 10-150
- `age`: 18-120 (predictor level; study protocol may be narrower)
- `systolic`: 70-250
- `diastolic`: 40-150

Study protocol for DIANA remains focused on postmenopausal women age 45-60.

---

## Output Columns

`run_validation.py` appends:

- `predicted_status`
- `risk_score`
- `risk_cluster`
- `diabetes_probability`
- `at_risk_probability`
- `model_auc` (from loaded `best_model_report.json`)

## Recommended Doctor Validation Workflow

1. Collect local cohort with clinician labels and confirmatory labs.
2. Run batch predictions with this script.
3. Compare against local ground truth:
   - sensitivity, specificity, PPV, NPV
   - confusion matrix by class
4. Record mismatch patterns (false positives, missed high-risk cases).
5. Review clinical workflow burden before any deployment decision.

## Troubleshooting

- **Clinical models missing**
  - run `bash scripts/dev/retrain-clinical.sh`
- **Artifact consistency check fails**
  - rerun the clinical_3class training pipeline and verify outputs
- **Input parsing errors**
  - validate numeric columns and required headers
