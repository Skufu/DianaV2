The Clinical Problem

Diabetes Risk Prediction for Postmenopausal Women

Building a machine learning model to identify women at risk of developing Type 2 diabetes based on metabolic biomarkers.

Why This Population?

  • Menopause causes metabolic shifts
  • Hormonal changes affect insulin sensitivity
  • Cardiovascular risk increases significantly
  • Early intervention improves outcomes

Clinical Goal

  • Screening tool, not diagnosis
  • High sensitivity for at-risk detection
  • Actionable risk stratification
  • Explainable predictions (SHAP)

⚠ Model is a clinical decision support tool — requires clinician review before action.

Data Source: NHANES

National Health and Nutrition Examination Survey

  • Representative sample of US population
  • Continuous survey since 1960s
  • Combines interviews & physical examinations

Cross-Validation: Why LOGO-CV?

Leave-One-Group-Out: The math behind temporal validation

The Problem

  • Data from 6 different time periods
  • Distribution shift between cycles
  • Standard K-Fold would leak information

The Solution

  • Each fold = one NHANES cycle
  • Train on 5 cycles, test on 1
  • Mimics real-world deployment
Total Folds: 6 (one per cycle)

Why This Matters

When model sees 2021-2023 data in production, it must have learned from 2009-2018 patterns — not leaked future information.

The Mathematics of K-Fold CV

How we estimate generalization error

CV Score = (1/K) × Σ AUC(Test Fold_i)

Algorithm

for each fold i in K:
    Train = all data except group i
    Test = group i only
    model.fit(Train)
    predictions = model.predict(Test)
    fold_score = roc_auc(Test, predictions)
    
return mean(fold_scores), std(fold_scores)

Benefits

  • Lower variance than single train/test split
  • Better use of data — every sample tested once
  • Unbiased estimate of generalization error
  • Detects overfitting patterns

Nested Cross-Validation

Two levels of cross-validation for model selection

Why Nested?

We need to both (1) select hyperparameters AND (2) estimate performance. Doing both on the same validation set leads to optimistic estimates.

Outer Loop

LOGO-CV (K=6 folds)

Estimates true generalization performance

Inner Loop

Grid search with 5-fold CV

Selects best hyperparameters

Nested CV prevents optimistic bias in performance estimates

Threshold Optimization

Finding the optimal classification boundary

Optimal Score = (0.35 * Sens) + (0.30 * Spec) + (0.25 * F1) + (0.10 * Acc)

*Custom clinical cost matrix deliberately penalizing false negatives

Default vs Optimal

Default (0.5) Sens=0.65, Spec=0.68
Optimal (0.455) Sens=0.75, Spec=0.57

Why This Matters

  • Medical screening needs high sensitivity
  • Missing a true case (false negative) is costlier than false alarm
  • Youden's J statistic balances both

SHAP Explanations

Understanding why the model makes each prediction

SHAP (SHapley Additive exPlanations)

  • Based on Shapley values from game theory
  • Assigns each feature an importance value for each prediction
  • Guaranteed to sum to the prediction difference from baseline
prediction = baseline + Σ SHAP(feature_i)

Key insight: Higher triglycerides and lower HDL push prediction toward "At-Risk"

Limitations & Considerations

What the model cannot do

Population Specificity

  • Only postmenopausal women (age 45-60)
  • US NHANES sample may not generalize globally

Missing Biomarkers

  • No blood pressure (not in recent cycles)
  • No fasting insulin or CRP
  • Family history mostly missing (83%)

Self-Reported Labels

  • Diabetes status from DIQ010 question
  • 6% disagreement with HbA1c
  • Introduces label noise

Not a Diagnostic

  • DO NOT use as standalone diagnosis
  • Requires clinician review
  • Complements, not replaces, clinical judgment
