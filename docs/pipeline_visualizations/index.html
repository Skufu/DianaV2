1. Pipeline Overview

DIANA transforms raw NHANES survey data into a clinical risk screening model through 6 stages:

Stage 1-2

NHANES Download

6 cycles of SAS XPORT files downloaded from CDC for 13+ file types per cycle: demographics, biomarkers, lifestyle questionnaires.

Stage 3-4

Label Assignment

Self-reported diabetes (DIQ010) + ADA HbA1c override. 3-class: Normal / Pre-diabetic / Diabetic. Binary target: Normal vs At-Risk.

Stage 5-6

Nested LOGO CV

Leave-One-Group-Out by NHANES cycle. Inner GroupKFold CV. 4 classifiers compared. Threshold optimization with guardrails.

2. Data Extraction — NHANES Multi-Cycle Download

Source

NHANES (National Health and Nutrition Examination Survey) — CDC's nationally representative health survey.

Cycles Downloaded

6 cycles spanning 2009-2023 (post-ADA HbA1c guidelines era). 2021-2023 is a 3-year cycle due to COVID-19.

File Types Per Cycle

  • DEMO — Demographics (age, gender, race)
  • GHB — Glycohemoglobin (HbA1c)
  • GLU — Fasting Glucose
  • TCHOL / HDL / TRIGLY — Lipid panel
  • BMX — Body Measures (BMI, waist circumference)
  • RHQ — Reproductive Health (menopause status)
  • SMQ / PAQ / ALQ — Lifestyle (smoking, activity, alcohol)
  • DIQ / MCQ — Diabetes questionnaire, family history
  • BPX / BPXO — Blood pressure (oscillometric from 2021+)
  • INS (2013+) / HSCRP (2015+) — Enrichment

3. Data Processing & Merging

Process: scripts/data/process_nhanes_multi.py

Each cycle's 13+ SAS XPT files are loaded via pyreadstat, merged on SEQN (respondent ID), then concatenated across cycles.

Inclusion Criteria (Hard Filters)

  • Female RIAGENDR == 2
  • Age 45-60 Perimenopausal window
  • Postmenopausal RHQ031 == 2 (no period in 12 months)
  • Complete HbA1c + FBS Core biomarkers required

Lifestyle Feature Engineering

  • Smoking — SMQ020 (ever 100+ cigs?) + SMQ040 (current?) → Never / Former / Current
  • Physical Activity — PAQ605/PAQ650/PAQ665 (vigorous work/recreation) → Sedentary / Moderate / Active
  • Alcohol — ALQ101 (ever drink?) + ALQ120Q/ALQ120U/ALQ130 (frequency × quantity) → Never / Light / Moderate / Heavy

Column Name Normalization

NHANES uses different column names across cycles (e.g., LBDHDD vs LBXHDD for HDL). The processor handles this with a first_existing_column() pattern.

Enrichment Features

Waist circumference (BMXWAIST), fasting insulin (LBXIN, 2013+), hs-CRP (LBXHSCRP, 2015+), and family history of diabetes (MCQ300C) are preserved when available.

4. Label Assignment & Data Cleaning

Process: Ian_ML/training/data_processing.py

Diabetes status labels are assigned using a self-report first strategy with ADA HbA1c override:

classify_diabetes_self_reported("DIQ010", hba1c):
  if hba1c >= 6.5: return "Diabetic" # ADA override
  if DIQ010 == 1: return "Diabetic"
  if DIQ010 == 3: return "Pre-diabetic"
  if DIQ010 == 2:
    if 5.7 <= hba1c < 6.5: return "Pre-diabetic"
    return "Normal"

Data Cleaning

  • Duplicate removal — SEQN-based deduplication
  • Outlier flagging (not removal) — Clinical range + IQR detection
  • Missing label drop — Only ~60 rows dropped post-filter
  • Binary target — Normal (0) vs At-Risk (Pre-diabetic + Diabetic = 1)

5. Biomarker Profiles by Diabetes Status

Distribution of key clinical biomarkers across Normal, Pre-diabetic, and Diabetic groups. These patterns drive the screening model.

HbA1c

Clear separation: Normal (median ~5.3%), Pre-diabetic (~5.8%), Diabetic (~6.6%+). Strongest discriminator but NOT used in screening model to avoid circular reasoning.

BMI & Triglycerides

Progressive increase across groups. Mean BMI: 28 (Normal) → 32 (Pre-diabetic) → 35 (Diabetic). Key features in the 9-feature screening model.

HDL

Decreasing HDL with worsening glycemic status (protective effect). Median: 60 (Normal) → 54 (Pre-diabetic) → 49 (Diabetic).

7. The Screening Model — 9 LR-Safe Features

No HbA1c. No FBS. No Derived Scores (circular reasoning avoidance).

The model uses only continuous biomarkers + ordinal lifestyle factors that are safe for logistic regression (no ratios, no composite scores by default).

Continuous Biomarkers (6)

  • BMI — Body mass index (kg/m²)
  • Triglycerides — Fasting triglycerides (mg/dL)
  • LDL — Low-density lipoprotein (mg/dL)
  • HDL — High-density lipoprotein (mg/dL)
  • Age — Years (45-60 range)
  • Waist Circumference — Central obesity proxy (cm)

Ordinal Lifestyle Features (3)

  • Smoking — Never(0) / Former(1) / Current(2)
  • Activity — Sedentary(0) / Moderate(1) / Active(2)
  • Alcohol — Never(0) / Light(1) / Moderate(2) / Heavy(3)

Feature Engineering (training-only)

  • BMI category — Philippine Asia-Pacific WHO cutoffs (Underweight <18.5, Normal 18.5-22.9, Overweight 23-24.9, Obese ≥25)
  • TG/HDL Ratio — Lipid atherogenicity index
  • Metabolic Syndrome Score — Count of: TG>150, HDL<50, BMI≥25, Waist≥80cm

Why "LR-Safe"? Logistic Regression assumes linear relationships and no multicollinearity. All 9 features are either continuous (linear scale) or ordinal (monotonic). No ratios or interaction terms that would violate assumptions.

8. Training — Nested LOGO Cross-Validation

Validation Strategy

Two-level cross-validation that prevents temporal data leakage and provides honest performance estimates:

  • Outer loop: Leave-One-Group-Out (LOGO) by NHANES cycle. Each fold trains on 5 cycles, tests on the 6th.
  • Inner loop: GroupKFold (3 splits) within training cycles for hyperparameter tuning.
  • Preprocessing inside CV: Imputation and scaling are fit on training folds only — no global leakage.

Models Compared

  • Logistic Regression — Linear, interpretable (BEST: AUC=0.737)
  • Random Forest — Non-linear ensemble
  • LightGBM — Gradient boosting
  • XGBoost — Gradient boosting

Threshold Optimization

Youden's J statistic (maximizing sensitivity + specificity - 1), with guardrails to prevent unstable low-threshold selection under temporal prevalence shift.

Winner

Logistic Regression

Voted best by mean fold AUC. Simpler, more stable across NHANES cycles.

10. Ahlqvist-Inspired Diabetes Subtypes

K-Means clustering (K=4) on at-risk patients only, approximating Ahlqvist et al. (2018) diabetes subtypes using available biomarkers.

Limitation Acknowledged: True Ahlqvist subtypes require HOMA2-B, HOMA2-IR, and C-peptide — not available in NHANES. DIANA uses proxy metrics per Tanabe et al. (2024) adaptation. SIDD is rebranded as "Atherogenic/Lipid-Driven" to reflect that it identifies high-LDL, not beta-cell dysfunction.

11. SHAP Feature Importance — What Drives Predictions?

SHAP (SHapley Additive exPlanations) values decompose each prediction into feature contributions. Positive SHAP = pushes toward At-Risk.

Top-3 Risk Drivers

  1. Triglycerides — Highest mean |SHAP|. High TG strongly pushes toward At-Risk.
  2. BMI — Second strongest. Every unit increase in BMI increases risk.
  3. Age — Older age within the 45-60 range contributes to higher risk.

Protective Factors

  • HDL — Negative SHAP values: higher HDL reduces risk (inverse relationship).
  • Physical Activity — Higher activity levels correlate with lower risk.

Color Interpretation (Beeswarm)

Red/Blue = high/low feature value. A red point on the right side means a high value of that feature pushes toward At-Risk. All features show the expected clinical direction.

12. Summary — What DIANA Does

Data Pipeline

  • 6 NHANES cycles (2009-2023), 13+ file types each → merged on SEQN
  • Inclusion: female, 45-60, postmenopausal, complete HbA1c+FBS
  • Labels: DIQ010 self-report + ADA HbA1c override → 1,376 records
  • 9 LR-safe features used for screening (no HbA1c/FBS)
  • Imputation handled inside CV (SimpleImputer, median strategy)

Model

  • Best: Logistic Regression (selected via nested LOGO CV)
  • AUC: 0.737 [95% CI: 0.710-0.763]
  • Sensitivity: 0.748 [95% CI: 0.717-0.776]
  • Specificity: 0.590
  • Threshold: 0.465 (Youden-optimized + guardrails)

Subtypes (K-Means K=4)

  • SIRD Insulin-Resistant — High BMI, TG, Low HDL
  • SIDD Atherogenic — High LDL (per Tanabe 2024)
  • MOD Obesity-Related — High BMI, moderate markers
  • MARD Age-Related — Older, milder profile

Key Design Constraints

  • No HbA1c/FBS in screening features (circular reasoning avoidance)
  • Nested CV prevents temporal data leakage
  • Threshold guardrails protect against prevalence shift
  • All constants in feature_constants.py — single source of truth
  • Philippine Asia-Pacific WHO BMI cutoffs (≥25 obese)
