> **Generated by**: `Ian_ML/training/train_binary_v2_no_bp.py`
> **Model Type**: Binary classifier (Normal vs At-Risk)
> **Validation**: Nested LOGO CV (Leave-One-Group-Out by NHANES cycle)
> **Population**: Postmenopausal women (45-60 years)

### 2. `blindspot_warnings.json`

**Purpose**: Identifies folds where models show concerning behavior (high FPR or FNR).

**Structure**: Array of fold-level records with anomalous metrics.

**Example Warning**:
```json
{
  "fold": 6,
  "test_cycle": "2021-2023",
  "model": "Logistic Regression",
  "fpr": 0.7279,  // 72.8% false positive rate - concerning
  "sensitivity": 0.9237  // Very high sensitivity, but at cost of specificity
}
```

**Interpretation**:
- High FPR folds may indicate distribution shift (different population in that cycle)
- Fold 6 (2021-2023) shows highest sensitivity but lowest specificity
- These warnings guide where the model may be less reliable

**Use Case**: Review before deployment to understand temporal stability issues.

---

### 3. `calibration_report.json`

**Purpose**: Assesses whether predicted probabilities match observed frequencies.

**Key Metrics**:
| Metric | Value | Interpretation |
|--------|-------|----------------|
| `brier_score` | 0.2082 | Lower is better (0 = perfect, 0.25 = random) |
| `expected_calibration_error` | 0.0624 | Average deviation from perfect calibration |
| `hosmer_lemeshow_statistic` | 21.40 | Chi-square measure (lower = better calibrated) |

**Calibration Curve**:
- `prob_pred`: Predicted probabilities (binned)
- `prob_true`: Observed frequencies in each bin
- Well-calibrated models have `prob_true ≈ prob_pred`

**Why It Matters**: For clinical screening, patients need accurate risk probabilities, not just binary predictions.

### 4. `cluster_analysis.json`

**Purpose**: K-Means clustering results with Ahlqvist diabetes subtype mapping.

**Cluster Subtypes (K=4)**:
| Cluster | Subtype | Risk Level | Key Characteristics | Diabetic Rate |
|---------|---------|------------|---------------------|---------------|
| SIRD | Severe Insulin-Resistant Diabetes | HIGH | High BMI, high TG, low HDL | 36.1% |
| SIDD | Atherogenic/Lipid-Driven | HIGH | High LDL, dyslipidemia | 26.1% |
| MOD | Mild Obesity-Related Diabetes | MODERATE | High BMI, moderate markers | ~20% |
| MARD | Mild Age-Related Diabetes | LOW | Older, mild metabolic dysfunction | 8.1% |

**Feature Weights**:
```json
{
  "bmi": 1.5,
  "triglycerides": 2.0,  // Highest weight - metabolic syndrome indicator
  "ldl": 2.5,            // Highest weight - cardiovascular risk
  "hdl": 1.2,
  "age": 1.0,
  "waist_circumference": 2.0
}
```

**Methodology Note**: K=4 was selected to match Ahlqvist et al. (2018) literature. Silhouette analysis suggested K=2, which may indicate menopausal population-specific patterns.

### 6. `inference_benchmark.json`

**Purpose**: Production latency benchmarks for model selection.

**Results**:
| Model | Mean (ms) | P95 (ms) | P99 (ms) |
|-------|-----------|----------|----------|
| Logistic Regression | 1.08 | 1.27 | 1.31 |
| LightGBM | 1.40 | 2.24 | 3.94 |
| Random Forest | 40.74 | 49.44 | 73.83 |

**Interpretation**:
- Logistic Regression is ~38x faster than Random Forest
- LR and LightGBM are both suitable for real-time inference
- Random Forest may be too slow for high-throughput production

**Production Recommendation**: Use Logistic Regression for inference speed, accept slight accuracy trade-off.

### 7. `logo_fold_metrics.csv`

**Purpose**: Detailed per-fold metrics for defensible validation.

**Columns**:
| Column | Description |
|--------|-------------|
| `Fold` | LOGO fold number (1-6) |
| `Test_Cycle` | NHANES cycle held out for testing |
| `Model` | Algorithm tested |
| `Inner_CV_AUC` | AUC from inner cross-validation (hyperparameter tuning) |
| `AUC_ROC` | Test set AUC for this fold |
| `Accuracy`, `Sensitivity`, `Specificity`, `PPV`, `NPV`, `F1` | Standard metrics |
| `Threshold` | Decision threshold used |
| `Best_Params` | Hyperparameters selected by inner CV |
| `FPR`, `FNR` | False positive/negative rates |
| `Balanced_Accuracy` | Average of sensitivity and specificity |

**Defensibility**: LOGO CV by NHANES cycle prevents temporal data leakage - each fold tests on a year group not seen during training.

### 8. `logo_summary_by_model.csv`

**Purpose**: Aggregated comparison of model performance across all folds.

**Key Findings**:
| Model | Mean AUC | Std AUC | Mean Sensitivity | Mean Specificity |
|-------|----------|---------|------------------|------------------|
| Logistic Regression | 0.7306 | 0.0248 | 0.7495 | 0.5786 |
| Random Forest | 0.7142 | 0.0207 | 0.7590 | 0.5574 |
| LightGBM | 0.7026 | 0.0163 | 0.7807 | 0.5011 |

**Interpretation**:
- Logistic Regression has highest mean AUC (0.7306)
- LightGBM has lowest variance (most stable across folds)
- All models have similar sensitivity; LR has best specificity

**Model Selection Rationale**: LR chosen for highest AUC, best calibration, and fastest inference.

### 9. `weighted_kmeans_sensitivity_analysis.csv`

**Purpose**: Tests robustness of cluster assignments to feature weight changes.

**Columns**:
| Column | Description |
|--------|-------------|
| `scenario` | Weight perturbation name (e.g., `bmi_minus20`) |
| `feature` | Feature being perturbed |
| `baseline_weight` | Original weight value |
| `perturbed_weight` | Modified weight value |
| `perturbation_percent` | Percentage change (-20%, -10%, +10%, +20%) |
| `assignment_stability_aligned` | Proportion of samples keeping same cluster |
| `adjusted_rand_index` | Similarity measure between original and perturbed assignments |
| `changed_assignments_percent_aligned` | % of samples that changed clusters |

**Key Findings**:
- Most perturbations result in >98% assignment stability
- `waist_circumference_minus20` shows highest instability (3.1% changed)
- `age` perturbations have minimal impact (0-0.17% changed)
- Clustering is robust to ±20% weight changes

**Use Case**: Justifies feature weight choices in thesis methodology section.
